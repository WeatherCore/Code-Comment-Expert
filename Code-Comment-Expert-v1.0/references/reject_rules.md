# 拒绝触发规则（何时不走本 skill，改走普通问答）

本 skill 只解决「通读项目 → 生成导航 + 意图级注释」。以下场景一律拒绝启动，用一句话说明原因并建议普通问答。

---

## 拒绝 1：纯算法题 / 单段独立代码
- **判定**：不存在完整项目目录、不存在多文件依赖关系，仅单段独立代码，无工程上下文，不需要构建项目图谱。
- **示例**：「请为我解释这段 LeetCode 回溯算法的每一行。」
- **处理**：走普通问答，逐行讲解即可。

## 拒绝 2：代码重构
- **判定**：需求目标是修改代码结构、调整业务实现，不聚焦注释生成与项目阅读导航。
- **示例**：「帮我把这个前端项目重构成 xxx 框架。」
- **处理**：走普通问答或重构类 skill。

## 拒绝 3：故障急救 / 调试
- **判定**：需求是诊断与修复（改代码逻辑、调依赖让项目跑起来），而非添加说明性注释。
- **示例**：「项目启动报错 BeanCreationException / ModuleNotFoundError，帮我改代码跑起来。」
- **处理**：本 skill 绝不自行修改纠错逻辑；可建议「请先运行调试/诊断类技能」。

## 拒绝 4：无项目结构（单文件脚本）
- **判定**：单文件或无标准项目结构（无 pom.xml / build.gradle / requirements.txt / pyproject.toml / go.mod 等），不具备「通读项目」前提。
- **示例**：「帮我写个带注释的爬虫脚本。」
- **处理**：走普通问答。

## 拒绝 5：项目对比 / 选型
- **判定**：目标是横向对比多个项目、做技术选型，而非通读其中一个并注释。
- **示例**：「帮我对比一下这几个项目的架构优劣。」
- **处理**：走普通问答。

---

## 触发前的快速自检（agent 执行）
1. 目标根目录是否存在构建文件且含多个源码文件？否 → 拒绝 1/4。
2. 用户意图是「加注释/出导航」还是「改结构/修 bug/对比」？后者 → 拒绝 2/3/5。
3. 目标是否真实工程目录（而非单文件）？否 → 拒绝 4。
